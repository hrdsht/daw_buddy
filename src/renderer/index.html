    Project folders

    Only these are read. The scan goes as deep as your folders go.

    Folder names to skip

    Never opened, never listed. Comma separated.

    Bounce webhook

    Optional. Paste a Discord, Slack or Zapier webhook URL and each new bounce is announced there. Leave blank to keep everything local.

    External and network drives

    Turn on if bounces on a network share go unnoticed. Uses more CPU.

    Shortcuts and linked folders

    A .lnk is an ordinary file and can't loop a scan. What can is a junction or symlink — it looks like a real folder but points elsewhere, sometimes at its own parent. Off skips both.

    Output folder

    Where processed audio is written. Created inside your first project folder, and skipped by the scan so its contents never come back as renders.
